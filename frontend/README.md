# API Sentinel — Frontend

The modern SOC-inspired security operations dashboard for **API Sentinel**.

---

## Features

- **Real-Time SOC Aesthetic**: Polished dark security UI with glassmorphism and subtle micro-animations.
- **Summary Metrics**: Overview of Documented, Observed, and Shadow endpoints with OWASP-aligned Risk Scoring.
- **Main Findings Panel**: Actionable discrepancy cards for Shadow Endpoints, Schema Drifts, and Parameter Drifts with direct AI reasoning triggers.
- **Observability Inventory Matrix**: Interactive table contrasting documented contracts against observed reality.
- **AI Analysis & Remediation Modal**: Technical root cause breakdowns, OWASP mapping, and suggested OpenAPI 3.0 YAML patches.
- **Instant Demo Mode**: Pre-loaded demo datasets allow judges and auditors to inspect the system with zero setup.

---

## Running Locally

```bash
# 1. Install dependencies
npm install

# 2. Start Vite dev server
npm run dev

# 3. Build for production
npm run build
```
